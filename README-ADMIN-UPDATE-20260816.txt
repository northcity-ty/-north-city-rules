North City 管理画面 便利機能アップデート 2026-08-16

追加・改善:
- ルール一括操作（公開/下書き、必読ON/OFF、カテゴリ移動）
- 既存の選択削除・複製を維持
- PC / スマホ切替プレビュー
- 表専用エディタ（行・列追加、本文へ自動反映）
- ルール検索の絞り込み（大タイトル、公開状態、必読）
- 編集内容の軽量自動保存（ブラウザlocalStorage、1.8秒停止後に保存。通信なし）
- 公開予約（指定日時以降のみ公開サイトに表示）
- 関連ルール設定と公開側リンク表示
- 変更履歴で「変更前 / 次の状態」を比較表示
- 管理トップに最近編集したルール5件

軽量化方針:
- 自動保存はサーバー通信せず端末内だけ
- 最近編集は5件だけ取得
- 公開予約判定は既存の公開API SQL内で実施
- 関連ルールは既存の公開ルールデータから参照し追加APIなし

D1:
worker.js が publish_at / related_rule_ids 列を自動追加します。
SQLの手動実行は不要です。

デプロイ:
このフォルダ一式を現在のリポジトリへ上書きして通常どおりデプロイしてください。

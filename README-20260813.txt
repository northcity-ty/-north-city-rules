North City 公開サイト調整版

今回の変更:
- R2 IMAGES binding をwrangler.jsoncへ反映
- ページ順を整理
  重要告知 → 現在のNorth City → 街について → 参加方法 → ルール → お知らせ → 変更履歴 → FAQ → ギャラリー → 公式X → Discord CTA
- 現在のNorth City: CRIME TIMEをJOIN STATUSへ変更
- 参加方法を5ステップ化
- ギャラリーをPC/スマホ共通の左右矢印カルーセル化
- スマホは横スワイプ対応
- 画像クリック/タップで拡大
- PCのカード一覧は横幅を活用し、個別ルール本文は読みやすい幅に制限
- FAQや開いたルールのPC表示も読みやすさを調整
- X公式プロフィールタイムラインを埋め込み（APIキー不要）
- スマホの基本デザインは維持

注意:
Xの公式埋め込みはX側の仕様・ブラウザのトラッキング防止設定等により表示されない場合があります。
その場合でも「公式Xを見る」ボタンは残ります。

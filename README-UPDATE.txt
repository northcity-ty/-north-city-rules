North City 正式ルール書き込み版

変更内容
- 公開サイトの変更履歴を最新5件までに変更
- 確定済みの正式ルールを初期データとして自動追加
- 正式な13大タイトル構成を反映
- 既存ルールは勝手に全削除しません
- 同じ正式ルールは slug で判定し、重複追加しません
- 管理画面から追加後の編集・選択削除が可能
- 運営規約は通常文書表示用のデータとして追加

使い方
1. ZIP内のファイルをリポジトリへ上書き
2. Cloudflareへデプロイ
3. 公開サイトまたは管理画面を一度開く
4. WorkerがD1へ不足している正式ルールを自動追加します

注意
- まだ内容が確定していないルールは勝手に補完していません。
- 仮ルールが残っている場合は管理画面の選択削除で消してください。

North City 管理画面 v3

今回の変更
- 大タイトル/中タイトル追加時の番号入力ダイアログを廃止
- 管理画面内でそのまま追加・編集
- 中タイトルは大タイトルを選んでから一覧表示
- 市民向けルール閲覧を階層式に変更
  大タイトル → 中タイトル → ルール一覧 → ルール詳細
- パンくず「ルール一覧 ＞ 大タイトル ＞ 中タイトル ＞ ルール名」
- 戻るボタン
- 検索は階層を無視して全ルールから直接検索
- 公開/下書き/廃止、復元、完全削除、複製、差分、履歴は維持
- 色やサイト全体のデザイン方針は変更していません

上書きするファイル
- worker.js
- admin.html
- admin.css
- admin.js
- script.js

style.cssについて
- 既存のstyle.cssの一番下に「style-addition.css」の中身を追加してください。
- 既存デザインを消さず、階層表示に必要な分だけ追加します。
